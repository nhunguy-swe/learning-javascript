## Giới thiệu (About)

Repo này lưu lại hành trình học **JavaScript** từ cơ bản đến nâng cao — mỗi thư mục là một chủ đề cụ thể, được đánh số theo thứ tự học, kèm ví dụ code minh họa. Mục tiêu là xây dựng nền tảng vững chắc để áp dụng JavaScript vào các dự án thực tế (frontend, Node.js) và tự động hóa kiểm thử (QA Automation).

JavaScript là một trong những ngôn ngữ lập trình phổ biến nhất cho phát triển web, giúp xây dựng ứng dụng động và tương tác.

## Cách chạy code

```bash
git clone https://github.com/nhunguy-swe/learning-javascript.git
cd learning-javascript
```

Mỗi thư mục là một bài học độc lập — mở file `.html` bằng trình duyệt (nếu có DOM) hoặc chạy file `.js` bằng Node.js:

```bash
cd 34-promise
node index.js
```
